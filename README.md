# IMBA

[![Minecraft](https://img.shields.io/badge/Minecraft-1.20.1-brightgreen.svg)](https://www.minecraft.net/)
[![Fabric Loader](https://img.shields.io/badge/Fabric%20Loader-0.15.11-orange.svg)](https://fabricmc.net/)
[![Java](https://img.shields.io/badge/Java-17-blue.svg)](https://adoptium.net/)

Серверно-клиентский мод для мини-игры в прятки на **Minecraft Fabric 1.20.1**. Игрок из команды `hider` превращается в блок или предмет окружения, а игрок из команды `seeker` должен найти его до окончания раунда и не потерять все сердца на ошибочных ударах.

> Мод должен быть установлен и на сервере, и у подключающихся клиентов.

## Основные возможности

- Маскировка игрока под блок через `/imba_mask` и под предмет через `/imba_mask_item`.
- Режим статуи с фиксацией маски, центрированием и привязкой предметов к рамкам или стенам.
- Поворот маски по осям X, Y и Z и лазание по стенам в режиме маски.
- Специальное поведение дверей, кнопок, порталов, лестниц, скалк-жил, фонарей, воды, лавы и `imba:potion_2d`.
- Автоматический цикл раунда: подготовка прячущегося, выпуск искателя, таймер на шкале опыта и возврат в лобби.
- Потеря сердец искателем за промахи и неправильные блоки; отключённая естественная регенерация.
- Выбор одной из 12 локаций; выдаваемая модель всегда соответствует выбранной локации.
- Инструмент администратора с GUI для настройки точек телепортации.
- Фотокамера локаций с квадратными снимками, удалением одного или сразу всех фото.
- Отдельный GUI-инструмент точной автопозиции `imba:potion_2d`.
- Игровые точки 12 локаций связаны с выбранной на панели локацией; старые тестовые координаты автоматически заменяются.
- Декоративные светящиеся ягоды нельзя собирать, а ягодная статуя совпадает с обычной моделью по высоте.
- `imba:potion_2d` при движении остаётся над поверхностью и не мерцает внутри зельеварки.
- Маска `imba:potion_2d` использует размер реального предмета и всегда рендерится с полной яркостью.
- Блоки без ванильной предметной формы получают отдельный предмет модели с динамической иконкой; старые модельные `hide_button` также корректно надеваются.
- `/imba_resync` очищает клиентские копии масок и заново синхронизирует их со всем сервером.
- После завершения поиска меч искателя удаляется немедленно, а удары вне фазы поиска не расходуют сердца.
- Отдельная вкладка творческого инвентаря **IMBA**.
- Интерактивная панель `imba:settings_panel` для времени, локации и числа жизней.
- Блок `imba:start_block`, запускающий выбранную локацию, с изменяемой надписью.
- Невидимая декоративная табличка для рамок и секретных проходов.

## Требования

| Компонент | Версия |
| --- | --- |
| Minecraft | `1.20.1` |
| Java | `17` |
| Fabric Loader | `0.15.11` или новее |
| Fabric API | `0.86.1+1.20.1` |

## Установка

1. Установите Fabric Loader для Minecraft 1.20.1.
2. Поместите Fabric API и собранный JAR IMBA в папку `mods` сервера и клиента.
3. Запустите игру один раз, чтобы мод создал конфигурационные файлы в папке `config`.
4. Создайте ванильные команды игроков:

```mcfunction
/team add hider
/team add seeker
/team join hider <игрок-прячущийся>
/team join seeker <игрок-искатель>
```

5. Настройте лобби и точки раундов, затем запустите раунд командой `/imba_round_start`.

## Сборка и запуск среды разработки

```bash
./gradlew build
```

Готовый JAR появится в `build/libs`.

```bash
./gradlew runClient
./gradlew runServer
```

Проект использует Java 17. При ошибках вида `Unsupported class file major version` проверьте `JAVA_HOME` и результат `java -version`.

## Игровой цикл

Значения по умолчанию:

- подготовка `hider` — **40 секунд**;
- поиск — **120 секунд**;
- возврат в лобби после завершения — **5 секунд**;
- здоровье `seeker` — **5 сердец**.

После запуска раунда `hider` сразу телепортируется на локацию и получает:

- предмет **«Скрыться»** в первом слоте;
- предмет **«Надеть модель …»** в девятом слоте.

`seeker` ждёт окончания подготовки в лобби с ограничением движения. После подготовки он телепортируется на локацию, а оставшееся время поиска отображается уровнем опыта.

## Управление маской

| Клавиша | Действие |
| --- | --- |
| `R` | поворот маски по оси Y |
| `X` | поворот по оси X |
| `Z` | поворот по оси Z |
| `C` | включение или отключение лазания по стенам |

Клавиши можно переназначить в стандартных настройках управления Minecraft в категории **IMBA — маски**.

## Команды

Все административные команды требуют уровень прав оператора 2.

### Маски

```mcfunction
/imba_mask <блок>
/imba_mask_item <предмет>
/imba_reset
```

Примеры:

```mcfunction
/imba_mask minecraft:oak_door
/imba_mask minecraft:water
/imba_mask minecraft:lava
/imba_mask minecraft:ladder
/imba_mask_item minecraft:apple
/imba_mask_item imba:potion_2d
```

### Управление раундом

```mcfunction
/imba_round_start
/imba_round_stop
/imba_round_pause
/imba_round_resume
/imba_round_reset
/imba_set_seeker_hearts <сердца>
/imba_set_prepare_time <секунды>
/imba_set_round_time <секунды>
/imba_set_return_time <секунды>
/imba_set_location <1..12>
```

Изменённые командами значения времени и здоровья начинают использоваться без перезапуска сервера.

### Тестирование и служебные команды

```mcfunction
/imba_timer_test_start <секунды>
/imba_timer_test_stop
/imba_give_seeker_sword
/imba_boosty <on|off|toggle>
/imba_messages [on|off|toggle]
```

`/imba_messages` без аргументов показывает текущее состояние необязательных игровых уведомлений.
По умолчанию они выключены: сообщения о промахах, потере сердца, надевании модели и
входе или выходе из режима статуи не засоряют чат и строку действий.

## Настройщик телепортов

Получить инструмент можно во вкладке **IMBA** или командой:

```mcfunction
/imba_tp_tool
```

Использование предмета открывает GUI, в котором доступны:

- `lobby` — точка лобби;
- `r1_hider` … `r12_hider` — точки появления прячущегося;
- `r1_seeker` … `r12_seeker` — точки появления искателя.

Введите X, Y и Z, выберите нужную точку и нажмите **«Сохранить»**. Значение применяется сервером сразу. Альтернативный режим настройки по нажатию на блок выбирается командой:

```mcfunction
/imba_tp_mode <режим>
```

## Конфигурация

Файлы создаются автоматически в `<папка сервера>/config`.

### `imba_portal.json`

Перенаправляет ванильный портал вместо обычного перехода в Незер:

```json
{
  "disableNether": true,
  "world": "minecraft:the_nether",
  "x": 0.5,
  "y": 80.0,
  "z": 0.5,
  "yaw": 0.0,
  "pitch": 0.0,
  "portalTicks": 80
}
```

- `world` и координаты задают подготовленную точку назначения;
- `portalTicks` задаёт длительность нахождения в портале до телепортации;
- при `disableNether: true` обычное перемещение в Незер отменяется.

### `imba_break_rules.json`

Список блоков, за которые искатель не теряет сердце:

```json
{
  "noPenaltyBreakBlocks": [
    "minecraft:brewing_stand"
  ]
}
```

### `imba_attachments.json`

Точные смещения для автоматического закрепления предметных масок:

```json
{
  "itemOffsets": {
    "imba:potion_2d": {
      "x": 0.0,
      "y": 0.15,
      "z": 0.0
    }
  }
}
```

После ручного редактирования JSON перезапустите сервер, чтобы конфиги были перечитаны. Изменения, сделанные через внутриигровой GUI, применяются сразу.

### Панели, камера и запуск

- Панель `imba:settings_panel` состоит из трёх колонок: **Таймер**, **Локация**, **Количество**. Нажатие по верхнему или нижнему блоку соответствующей колонки изменяет значение.
- В центре панели показывается квадратная фотография выбранной локации. При отсутствии снимка используется нейтральная заглушка.
- Предмет `imba:location_camera` открывает галерею 12 локаций. В ней можно сделать снимок, удалить одно или все фото, задать название локации, выбрать связанную маску из списка с русскоязычным поиском и телепортироваться к выбранной локации.
- В камере также есть быстрые телепорты в лобби и скрытый кинотеатр. Координаты всех точек встроены по строительному ТЗ.
- Если название локации пустое, панель показывает её номер; если название задано, отображается только оно.
- Предмет `imba:potion_offset_tool` открывает отдельный GUI смещения X/Y/Z для `imba:potion_2d`.
- Обычный ПКМ по `imba:start_block` запускает игру с выбранной локацией. Shift+ПКМ открывает изменение надписи блока.
- `imba:invisible_sign` не имеет видимой модели, текста и физической коллизии, но служит опорой для рамок.

### Автоматическая установка после сборки

На компьютере пользователя команда `gradlew build` после успешной сборки заменяет старый JAR в двух профилях, если их папки существуют:

- `C:\Users\honor\AppData\Roaming\ModrinthApp\profiles\Имба прятки\mods`
- `C:\Users\honor\AppData\Roaming\ModrinthApp\profiles\Имба прятки (1)\mods`

На других компьютерах отсутствующие папки просто пропускаются.

## Зарегистрированный контент

Основные идентификаторы мода:

- `imba:hide_button`;
- `imba:potion_2d`;
- `imba:teleport_tool`;
- `imba:potion_offset_tool`;
- `imba:location_camera`;
- `imba:glowberries`;
- `imba:grass`;
- `imba:ladder`;
- `imba:hanging_lantern`;
- `imba:settings_panel`;
- `imba:start_block`;
- `imba:invisible_sign`;
- элементы модели камнереза `imba:stonrcutter_block` и `imba:stonrcutter_lezvie`.

Технические блоки `water_mask`, `lava_mask` и `ladder_mask` используются внутренним рендером масок и не предназначены для обычной выдачи игрокам.
